## 1. `data.sql` のINSERT順序の修正

**ファイル：** `src/main/resources/data.sql`

**問題：** `prefectures` と `acm_categories` のINSERTがファイル末尾（137〜189行目）にあるが、それより前の `users`（prefecture_id参照）や `accommodations`（prefecture_id, category_id参照）が先に実行されるため外部キー違反が起きる。

**修正：** ファイル末尾の以下2つのINSERT文（137〜189行目）を切り取り、ファイルの**先頭**に移動する。

```sql
-- この2ブロックを切り取ってファイル先頭に移動
INSERT INTO prefectures(name) VALUES ('北海道'), ... , ('沖縄県');
INSERT INTO acm_categories(name) VALUES ('ホテル'), ('ビジネスホテル'), ('ホステル'), ('旅館');
```

移動後の順序：`prefectures` → `acm_categories` → `admins` → `users` → `accommodations` → `plans` → `plan_stocks` → `reservations`
